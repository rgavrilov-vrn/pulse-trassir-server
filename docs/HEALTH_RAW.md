# Health и raw_sdk

## Статус
Расширения находятся в features.py, Collector из этого модуля наследует базовый Collector из core.py. Схема SQLite, Sender и подтверждение HTTP 200 не меняются. SDK settings передаётся из scripts/collector.py. Доступность settings('health') и полей требуется проверить на вашей сборке; код не обращается к неподтверждённому server.health.

## Обновление
1. Остановите оба SDK-скрипта, сохраните конфиг и согласованную копию БД.
2. Скопируйте features.py рядом с core.py; core.py должен уже содержать исправление threading.local.
3. Обновите СОДЕРЖИМОЕ SDK-скрипта Collector из scripts/collector.py: простого копирования файла недостаточно.
4. Добавьте health и raw_sdk из примера в локальный config.json, не заменяя server_id, URL, токен и storage.
5. Обеспечьте загрузку новых модулей без старых обработчиков и дублирующих подписок. Reload сам не заменяет существующий app.
6. Сначала проверьте сбор при выключенном Sender; затем согласуйте приём новых событий и включите Sender.
Старый config без новых разделов сохраняет прежнее поведение: обе возможности выключены. Новые ключи применяются динамически, но новый код и SDK-точку входа нужно загрузить один раз. Не меняйте server_id и не пересоздавайте БД ради обновления.

## Health
Событие trassir.health, event_version=1.0; пакет остаётся contract_version=1.0. Объект data содержит metrics, missing_fields, collection_errors, source и snapshot_atomic=false. Чтение полей последовательное, не атомарный снимок. observed_at создаётся после сбора; occurred_at=null. Числовые значения не угадываются из строк, исходная семантика сохраняется. Отсутствующие показатели не равны нулю. KeyError попадает в missing_fields, остальные исключения — в collection_errors с типом ошибки без текста. Ошибка всего settings('health') тоже сохраняется в снимке.
Интервал 60 секунд по умолчанию, диапазон 5..86400; фактическая частота зависит от SDK tick. Одно неисправное поле не отменяет остальные. Collector.enabled=false выключает и health. Не включайте неизвестные поля: допустимый список HEALTH_FIELDS в features.py. CPU/GPU, устройства/каналы, диски/архив, БД, скрипты/плагины, сеть и лицензия читаются только по этому списку; cloud SID/аккаунты не собираются. Изменения списка полей и интервала — через health.fields/interval_seconds.

## raw_sdk
При enabled=true системные SDK-события получают event_version=1.1 и дополнительный raw_sdk. Это ограниченный снимок выбранных атрибутов, НЕ весь живой объект и НЕ автоматический dir-обход. Нормализованные data/source сохраняются. Для heartbeat, health и файловых логов raw_sdk не добавляется. По умолчанию type, ts, origin, p1, p2, p3. Дополнительные проверенные имена можно добавить через attributes. Методы не вызываются, приватные имена, origin_object и имена с признаками секретов запрещены. Не добавляйте чувствительные данные вручную; blacklist не является гарантией обезличивания.
Лимиты: 64 атрибута, 32 КиБ всего raw_sdk в UTF-8 вместе с метаданными, 4 КиБ на строку, 3 уровня контейнеров, 50 элементов в контейнере. Ограничены также пути диагностик и ключи. raw_sdk содержит attributes, unavailable_attributes, limitations, truncated. Числа NaN/Infinity заменяются null с отметкой. Неизвестные вложенные SDK-объекты не преобразуются через repr. Циклы останавливаются. Лимиты относятся к результату, а не к жёсткому времени выполнения SDK-getter; один getter всё ещё может задержать callback. Большой нормализованный data сам по себе не ограничен raw_sdk и может попасть в quarantine при упаковке.

## Ошибки настроек и диагностика
Для расширений отдельно проверяются типы/списки. При неверных новых настройках предыдущие настройки расширений сохраняются, диагностируется Feature settings rejected; базовые настройки по-прежнему обрабатывает ConfigManager. В старом конфиге расширения выключены.
Ищите trassir.health и raw_sdk в JSONL и SQLite. Отладчик с SHOW_HEARTBEAT=false показывает health, но raw_sdk появится только после реального SDK-события. Если metrics пуст, проверьте collection_errors и серверный контекст. Наличие heartbeat не подтверждает подписку на SDK.
Это расширение не исправляет оставшуюся совместимость именованного доступа sqlite3.Row с Unicode в Python 2.7 внутри Sender: если там возникнет Index must be int or string, требуется отдельная правка чтения строк. Не выдавайте успешный health за проверенную доставку.
