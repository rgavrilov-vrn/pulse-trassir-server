# Утилиты для TRASSIR

## reload_modules.py
Одноразовый серверный скрипт Python 2.7. Добавлен на основе пользовательского скрипта: восстановлены отступы, profiles перезагружается перед object_states, в конце добавлен device_snapshot.

1. Остановите Collector и Sender проверенным способом, убедитесь, что прежние обработчики больше не выполняются.
2. Убедитесь, что актуальные файлы всех перечисленных модулей находятся в C:\TRASSIR_Agent\src\trassir_agent.
3. Создайте отдельный одноразовый скрипт в серверном редакторе TRASSIR, вставьте содержимое reload_modules.py и выполните один раз. Функцию message предоставляет окружение TRASSIR.
4. При успешном выполнении получите путь core.__file__ и подтверждение EventRepository.db is a property: OK.
5. Запускайте Collector/Sender с новыми экземплярами приложений и актуальными точками входа. Не возвращайте старые экземпляры app.

Порядок reload: core -> features -> inventory -> object_health -> profiles -> object_states -> unified_snapshot -> device_snapshot. Утилита не изменяет config.json, БД или очередь, не создаёт app, подписки и таймеры и не останавливает старые обработчики самостоятельно. Импорт/reload обновляет определения модулей только в текущем интерпретаторе: если скрипты работают в разных интерпретаторах, их нужно обновлять отдельно.

Проверка property структурная: она не доказывает корректность многопоточного поведения SQLite и не исправляет проблему sqlite3.Row/Unicode в Sender. При ошибке не запускайте рабочие сборщики до выяснения причины. Существующая точка входа Collector также выполняет собственную согласованную перезагрузку необходимых ей модулей; эта утилита предназначена для ручного обслуживания и диагностики.
